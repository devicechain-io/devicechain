## en

- **Fleet operation readiness (Preview).** The `fleetOperationReadiness` query and `dcctl fleet-op readiness` report whether this instance can run fleet operations. In this release they report that enforcement is not installed and no operation kind is executable, which is expected. Requires `fleet:operate`; scoped members are refused. The preview clock starts at v1.9.

## es

- **Preparación de operaciones de flota (Preview).** La consulta `fleetOperationReadiness` y `dcctl fleet-op readiness` indican si esta instancia puede ejecutar operaciones de flota. En esta versión informan de que el cumplimiento no está instalado y ningún tipo de operación es ejecutable, lo cual es lo esperado. Requiere `fleet:operate`; se rechazan los miembros con ámbito limitado. El plazo de vista previa comienza en v1.9.

## zh-CN

- **设备群操作就绪检查（Preview）。** `fleetOperationReadiness` 查询和 `dcctl fleet-op readiness` 命令报告此实例是否可以运行设备群操作。在此版本中，它们报告尚未安装强制执行机制，且没有可执行的操作类型，这是预期结果。需要 `fleet:operate` 权限；具有受限范围的成员无法使用。预览期限从 v1.9 开始。
