## en

- **System settings keep what you just saved.** On **System settings**, a setting saved or reset while the list was still reloading briefly showed its previous value, and an edit made in that moment was built on it, so the next save quietly undid the first. The page now shows the value the server stored as soon as the save answers.

## es

- **Los ajustes del sistema conservan lo que acaba de guardar.** En **Ajustes del sistema**, un ajuste guardado o restablecido mientras la lista aún se recargaba mostraba por un momento su valor anterior, y una edición hecha en ese instante partía de él, de modo que el siguiente guardado deshacía el primero sin avisar. La página muestra ahora el valor que almacenó el servidor en cuanto responde el guardado.

## zh-CN

- **系统设置会保留您刚刚保存的内容。** 在**系统设置**页面中，若在列表仍在重新加载时保存或重置某项设置，页面会短暂显示其先前的值；此时所做的编辑基于该旧值，因此下一次保存会悄无声息地撤销第一次保存。现在，保存一旦返回，页面就会显示服务器所存储的值。
