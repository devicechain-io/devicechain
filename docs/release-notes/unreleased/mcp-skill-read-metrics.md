## en

- **MCP build identity and skill usage.** MCP now reports its build version and exports `devicechain_mcp_skill_reads_total{skill,kind}` for successful skill prompt and resource reads. Labels are limited to embedded skill names and `prompt` or `resource`; no upgrade action is required.

## es

- **Versión y uso de habilidades de MCP.** MCP ahora informa de la versión de compilación y exporta `devicechain_mcp_skill_reads_total{skill,kind}` para las lecturas correctas de prompts y recursos de habilidades. Las etiquetas se limitan a los nombres de las habilidades incluidas y a `prompt` o `resource`; no se requiere ninguna acción al actualizar.

## zh-CN

- **MCP 构建版本与技能使用情况。** MCP 现在报告其构建版本，并通过 `devicechain_mcp_skill_reads_total{skill,kind}` 统计成功的技能提示和资源读取。标签仅包含内嵌技能名称以及 `prompt` 或 `resource`；升级时无需任何操作。
