## en

- **Harborpulse tenant isolation and MCP questions.** The validation rig now checks two tenants with matching device identifiers and compares fleet answers from the real MCP service with GraphQL truth. It registers a public OAuth client per run and uses a tenant member's PKCE user token. Two planted defects prove each new check can fail independently.

## es

- **Aislamiento de tenants y preguntas MCP en Harborpulse.** El banco de validación comprueba dos tenants con identificadores de dispositivo iguales y compara las respuestas del servicio MCP real con los datos de GraphQL. Registra un cliente OAuth público por ejecución y usa el token de usuario PKCE de un miembro del tenant. Dos defectos provocados demuestran que cada comprobación puede fallar de forma independiente.

## zh-CN

- **Harborpulse 租户隔离和 MCP 问答。** 验证工具现可检查使用相同设备标识符的两个租户，并将真实 MCP 服务返回的设备群答案与 GraphQL 数据比较。每次运行都会注册一个公共 OAuth 客户端，并使用租户成员通过 PKCE 获取的用户令牌。两个植入缺陷分别验证两项新检查能够独立发现错误。
