## en

- **System settings in Simplified Chinese.** With the console set to 简体中文, the **System settings** screen is now translated, including its token-mask, language, map and branding editors. Its translation already existed but was never loaded, so the screen showed in English.

## es

- **Ajustes del sistema en chino simplificado.** Con la consola en 简体中文, la pantalla **Ajustes del sistema** está ahora traducida, incluidos sus editores de máscaras de token, idioma, mapa y marca. Su traducción ya existía pero nunca se cargaba, por lo que la pantalla se mostraba en inglés.

## zh-CN

- **系统设置提供简体中文。** 将控制台设置为简体中文后，**系统设置**界面现已翻译，包括令牌掩码、语言、地图和品牌编辑器。其译文此前已存在但从未加载，因此该界面一直显示为英文。
