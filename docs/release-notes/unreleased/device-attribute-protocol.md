## en

- Device-management exposes `device_attribute_orphans_removed_total{table}` to count orphaned device attribute rows removed during rolling-upgrade cleanup, by table.

## es

- Device-management incorpora `device_attribute_orphans_removed_total{table}` para contar, por tabla, las filas huérfanas de atributos de dispositivos eliminadas durante la limpieza de una actualización gradual.

## zh-CN

- Device-management 新增 `device_attribute_orphans_removed_total{table}` 指标，按表统计滚动升级清理期间删除的孤立设备属性行数。
