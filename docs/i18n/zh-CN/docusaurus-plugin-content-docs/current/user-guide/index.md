# 用户指南

本指南按照控制台自身导航的顺序，逐个界面介绍 DeviceChain Web 控制台。每一章说明某个界面的用途、
适用场景和预期结果，并配有已发布版本控制台的截图。

本指南讲解如何**在控制台中**工作。通过 API 或在设备一侧完成的任务（例如连接设备或通过代码发送命令），请参阅[指南](/category/guides)。

本指南面向两类读者：

- **租户用户和管理员**：处理某个租户的设备、规则、告警和仪表板。大部分章节面向你。
- **实例运维人员**：管理整个安装环境，包括租户、层级、身份和身份提供商。这些界面集中在单独的一章中。

初次使用 DeviceChain？请先阅读[你的第一台设备](../quickstart/first-device.md)让数据流动起来，
然后回到这里了解控制台。若想了解各组成部分如何协同工作，请参阅[概念](../concepts/architecture.md)部分。
