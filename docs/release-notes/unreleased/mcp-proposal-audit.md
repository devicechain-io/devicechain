## en

- **MCP proposal auditing.** Audit schema 3 adds `proposal` and `verdict` to tool-call logs: Preview proposal tools record the stored proposal token and platform decision with allowlisted refusal codes. Reads leave both fields empty; existing audit fields keep their meanings.

## es

- **Auditoría de propuestas MCP.** El esquema de auditoría 3 añade `proposal` y `verdict` al registro de llamadas: las herramientas de propuestas en Preview registran el token guardado y la decisión de la plataforma con códigos de rechazo permitidos. Las lecturas dejan ambos campos vacíos; los campos existentes conservan su significado.

## zh-CN

- **MCP 提议审计。** 审计格式版本 3 在工具调用日志中新增 `proposal` 和 `verdict`：Preview 提议工具记录已保存提议的令牌、平台裁决及允许记录的拒绝代码。读取操作的这两个字段为空，现有审计字段的含义保持不变。
