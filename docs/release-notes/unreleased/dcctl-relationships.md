## en

- **Manage entity relationships from dcctl.** Use `dcctl relationship add`, `list` and `remove` to create, inspect and remove typed relationships through the tenant API. The commands support `--instance` or `--server`, two-factor sign-in, and table or JSON output (`--json` or `--output json`). List supports pagination and source, target, relationship type and tracked filters.

## es

- **Gestiona relaciones entre entidades con dcctl.** Usa `dcctl relationship add`, `list` y `remove` para crear, consultar y eliminar relaciones tipadas mediante la API del tenant. Los comandos admiten `--instance` o `--server`, inicio de sesión con segundo factor y salida en tabla o JSON (`--json` o `--output json`). El listado admite paginación y filtros por origen, destino, tipo de relación y seguimiento.

## zh-CN

- **通过 dcctl 管理实体关系。** 使用 `dcctl relationship add`、`list` 和 `remove`，通过租户 API 创建、查看和删除有类型的实体关系。这些命令支持 `--instance` 或 `--server`、双因素登录，以及表格或 JSON 输出（`--json` 或 `--output json`）。列表支持分页，并可按来源、目标、关系类型和是否跟踪进行筛选。
