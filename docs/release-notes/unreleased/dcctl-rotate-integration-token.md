## en

- **Issue integration bearer tokens from dcctl.** Run `dcctl product rotate-integration-token <integration-token>` after creating a LoRaWAN or webhook integration. Capture the new token from stdout; it is shown only once, and the previous token stops working immediately with no overlap.

## es

- **Emite tokens de integración desde dcctl.** Ejecuta `dcctl product rotate-integration-token <integration-token>` después de crear una integración LoRaWAN o webhook. Captura el nuevo token desde stdout; se muestra una sola vez y el token anterior deja de funcionar inmediatamente, sin solapamiento.

## zh-CN

- **通过 dcctl 签发集成令牌。** 创建 LoRaWAN 或 webhook 集成后，运行 `dcctl product rotate-integration-token <integration-token>`。从标准输出捕获新令牌；它仅显示一次，旧令牌会立即失效，没有重叠有效期。
