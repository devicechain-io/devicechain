## en

- **Instance configuration schema for each release.** Download `instance-config.schema.json` from the exact target GitHub Release, or run that release's `dcctl config-schema` to obtain the same schema offline. Generated from the Go config types, it validates the instance document's structure and rejects unknown keys. Startup still checks semantic and cross-field constraints.

## es

- **Esquema de configuración de instancia por versión.** Descargue `instance-config.schema.json` de la versión de destino exacta en GitHub, o ejecute `dcctl config-schema` de esa versión para obtener el mismo esquema sin conexión. Se genera a partir de los tipos de configuración de Go, valida la estructura del documento de instancia y rechaza claves desconocidas. El arranque sigue comprobando las restricciones semánticas y entre campos.

## zh-CN

- **每个版本均提供实例配置模式。** 从目标版本的 GitHub Release 下载 `instance-config.schema.json`，或运行该版本的 `dcctl config-schema` 离线获取相同模式。该模式从 Go 配置类型生成，用于验证实例文档的结构并拒绝未知键。启动时仍会检查语义约束和跨字段约束。
