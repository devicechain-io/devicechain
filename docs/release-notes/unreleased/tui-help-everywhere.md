## en

- **Help on every screen of the install and setup terminal UI.** `?` or F1 now opens help on the
  welcome, preflight, cluster choices, advanced settings, context picker and review screens, on the
  progress screen, and on `dcctl setup local`'s hand-over and instance review, as it already did on
  the result screen. Help lists exactly the keys the screen's footer shows, says what the screen
  does, scrolls on a small terminal, and changes nothing: it never answers a question, never pauses
  the install, and on a screen whose approval starts something the screen waits for the keyboard to
  be quiet again after help closes. F1 also works while you type a name, where `?` is part of the
  name. Plain output (`--ui=plain`) is unchanged.

## es

- **Ayuda en todas las pantallas de la interfaz de terminal de instalación y configuración.** `?` o
  F1 abren ahora la ayuda en las pantallas de bienvenida, comprobaciones previas, opciones del
  clúster, ajustes avanzados, selector de contexto y revisión, en la pantalla de progreso, y en la
  entrega y la revisión de la instancia de `dcctl setup local`, como ya ocurría en la pantalla de
  resultado. La ayuda enumera exactamente las teclas que muestra el pie de la pantalla, explica lo
  que hace la pantalla, se desplaza en un terminal pequeño y no cambia nada: nunca responde a una
  pregunta, nunca pausa la instalación y, en una pantalla cuya aprobación pone algo en marcha, la
  pantalla espera a que el teclado vuelva a estar en calma después de cerrar la ayuda. F1 también
  funciona mientras escribes un nombre, donde `?` forma parte del nombre. La salida simple
  (`--ui=plain`) no cambia.

## zh-CN

- **安装和设置终端界面的每个屏幕都提供帮助。** 现在，在欢迎、预检、集群选项、高级设置、上下文选择和审阅屏幕上，在进度屏幕上，以及在 `dcctl setup local` 的交接屏幕和实例审阅屏幕上，按 `?` 或 F1 都会打开帮助，与结果屏幕上已有的行为相同。帮助列出的按键与屏幕底部显示的完全相同，说明该屏幕的作用，在较小的终端中可以滚动，并且不会更改任何内容：它从不回答问题，从不暂停安装；在批准后会启动操作的屏幕上，关闭帮助后该屏幕会等键盘再次安静下来。输入名称时（`?` 是名称的一部分）F1 同样可用。普通输出（`--ui=plain`）保持不变。
