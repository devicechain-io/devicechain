# Reviewed exceptions for hack/govulncheck.sh.

# Format:  <module-dir> <OSV-ID> # why it cannot be fixed, and what would fix it
#
# An entry here is a decision, not a mute button. Three properties keep it honest:
#
#   - it is scoped to ONE module, so it cannot silence the same advisory elsewhere;
#   - the justification is mandatory and the checker rejects a line without one;
#   - it EXPIRES LOUDLY. If the vulnerability stops being reachable, the stale
#     entry fails the build until someone deletes it. An exception nobody has to
#     revisit is `continue-on-error` with extra steps.
#
# Add a line only when there is genuinely no fixed version to move to. If a fix
# exists, take the fix.

backend/cli GO-2026-5932 # x/crypto/openpgp, reached via helm.sh/helm/v3/pkg/action's package-init chain (bootstrap/helm.go). Advisory is "unmaintained, unsafe by design" with Fixed in: N/A — there is no patched x/crypto to move to, and helm v3.21.3 is the latest v3. Reachability is init-only: dcctl never performs an OpenPGP operation, it links the code because helm registers provenance verification at init. Removed when helm drops the dependency (helm v4 is the likely route) or dcctl stops embedding helm's action package.

# ---------------------------------------------------------------------------
# github.com/lib/pq — seven advisories published 2026-08-18, all Fixed in: N/A.
#
# THE SHARED REASON, written once here and referenced by each line below so the
# per-entry justifications stay about their own advisory.
#
# lib/pq is not imported anywhere in this repository. It is an indirect
# requirement of backend/cli alone, pulled in by helm.sh/helm/v3/pkg/storage/driver,
# which offers a SQL backend for storing Helm release state. dcctl embeds helm's
# action package, and Go links whole packages, so the code is present.
#
# It is never entered. helm's action.Configuration.Init constructs the SQL driver
# in exactly one place — `case "sql":` — and dcctl passes the LITERAL string
# "secret" at both of its call sites (bootstrap/helm.go:45 and :275). There is no
# variable, no flag and no configuration path that reaches the other branch, and
# even inside it the connection string comes from HELM_DRIVER_SQL_CONNECTION_STRING,
# which dcctl never sets. govulncheck reports the branch because its call-graph
# analysis does not evaluate the switch, which is the correct conservative answer
# for a static tool and an over-approximation here.
#
# 🔑 Every one of the seven is in the connection or wire-protocol path: parsing
# frames a Postgres server sent, or authenticating to one. Reaching any of them
# requires an open pq connection, and dcctl opens none.
#
# There is no version to move to (lib/pq is in maintenance and every advisory says
# Fixed in: N/A) and no way to drop the dependency short of dcctl no longer
# embedding helm — the same escape route the openpgp entry above is waiting on.
# These lines go when that happens, and the staleness check will say so.
# ---------------------------------------------------------------------------
