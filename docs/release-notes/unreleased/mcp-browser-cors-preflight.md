## en

- **Browser MCP clients.** The MCP endpoint now answers CORS preflights and exposes session and authentication challenge headers, allowing browser clients to connect with bearer tokens. No operator action is required.

## es

- **Clientes MCP en el navegador.** El endpoint MCP ahora responde a las solicitudes preliminares CORS y expone las cabeceras de sesión y de desafío de autenticación, lo que permite conectar clientes de navegador mediante tokens bearer. No se requiere ninguna acción del operador.

## zh-CN

- **浏览器 MCP 客户端。** MCP 端点现在响应 CORS 预检请求，并公开会话和身份验证质询响应头，允许浏览器客户端使用 bearer 令牌连接。运维人员无需执行任何操作。
