## en

- **Bulk configuration changes (Preview).** Boolean and numeric values now use the same canonical storage format as individual attribute writes, so selectors match correctly after a bulk post. Invalid typed values are refused during preview and creation. Successful posts and reversals also update dynamic-threshold facts immediately.

## es

- **Cambios masivos de configuración (Preview).** Los valores booleanos y numéricos ahora usan el mismo formato canónico de almacenamiento que las escrituras individuales de atributos, para que los selectores coincidan correctamente tras aplicar un cambio masivo. Los valores no válidos para su tipo se rechazan durante la vista previa y la creación. Las aplicaciones y reversiones correctas también actualizan de inmediato los datos de los umbrales dinámicos.

## zh-CN

- **批量配置更改（Preview）。** 布尔值和数值现在采用与单独写入属性相同的规范存储格式，确保批量应用后选择器能正确匹配设备。预览和创建操作时会拒绝不符合声明类型的值。成功应用更改或撤销更改后，也会立即更新动态阈值数据。
