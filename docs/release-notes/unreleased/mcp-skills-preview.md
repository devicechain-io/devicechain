## en

- **MCP skills (Preview).** The MCP server now offers three skills, written procedures that guide an assistant through common multi-step work with the existing tools: `alarm-storm-triage`, `device-anomaly-investigation` and `propose-change-for-approval`. They are served as prompts, as `skill://` resources and from the server's instructions, are the same for every caller, and grant nothing: every step is an ordinary tool call. The MCP page also now says that client self-registration is planned through Client ID Metadata Documents rather than dynamic client registration.

## es

- **Skills de MCP (vista previa).** El servidor MCP ofrece ahora tres skills, procedimientos escritos que guían a un asistente en tareas habituales de varios pasos con las herramientas existentes: `alarm-storm-triage`, `device-anomaly-investigation` y `propose-change-for-approval`. Se sirven como prompts, como recursos `skill://` y desde las instrucciones del servidor, son las mismas para todos los usuarios y no conceden nada: cada paso es una llamada a herramienta normal. La página de MCP indica además que el autorregistro de clientes está planeado mediante Client ID Metadata Documents en lugar del registro dinámico de clientes.

## zh-CN
