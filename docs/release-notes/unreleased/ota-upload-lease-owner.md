## en

- **Artifact upload ownership.** An expired upload can no longer release or complete a newer upload's lease, preserving one upload per artifact across replicas. No operator action is required.

## es

- **Propiedad de las cargas de artefactos.** Una carga caducada ya no puede liberar ni completar la concesión de una carga posterior, lo que mantiene una sola carga por artefacto entre réplicas. No se requiere ninguna acción del operador.

## zh-CN

- **制品上传租约归属。** 已过期的上传无法再释放或完成后续上传持有的租约，确保多个副本之间每个制品同时只有一个上传。运维人员无需采取任何操作。
