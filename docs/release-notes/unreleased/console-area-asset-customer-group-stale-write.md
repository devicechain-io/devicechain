## en

- **The console no longer overwrites someone else's change to an area, asset, customer or group.** Editing the name, description or type of an area, asset or customer, or the name or description of an area, asset, customer or device group, now sends the version the form was opened on. If someone else saved a change in the meantime, the save is refused with a message that says so, and what you typed stays in the form. Previously the later save silently replaced the earlier one.

## es

- **La consola ya no sobrescribe el cambio de otra persona en un área, un activo, un cliente o un grupo.** Al editar el nombre, la descripción o el tipo de un área, un activo o un cliente, o el nombre o la descripción de un grupo de áreas, activos, clientes o dispositivos, se envía ahora la versión con la que se abrió el formulario. Si otra persona guardó un cambio entretanto, el guardado se rechaza con un mensaje que lo indica, y lo que escribiste se conserva en el formulario. Antes, el guardado posterior reemplazaba en silencio al anterior.

## zh-CN

- **控制台不再覆盖他人对区域、资产、客户或分组所做的更改。** 编辑区域、资产或客户的名称、描述或类型，或编辑区域、资产、客户或设备分组的名称或描述时，控制台现在会发送打开表单时的版本。如果在此期间他人已保存了更改，此次保存会被拒绝并给出相应提示，你输入的内容仍保留在表单中。此前，后一次保存会悄无声息地替换前一次。
