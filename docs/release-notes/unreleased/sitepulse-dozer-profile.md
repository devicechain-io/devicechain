## en

- **The Site Pulse demo's dozers have their own device profile.** A dozer carries no load and has no tyres, yet it shared the equipment profile with the loaders and haul trucks, so the fleet table declared payload and tyre pressure for it and showed "no data in range". The dozer type now uses a profile of its own that declares fuel, engine temperature and engine hours only, with the same commands and the low-fuel and overheat rules but no tyre rule, so those cells read "does not report this". A demo instance created by an earlier release keeps the shared profile until it is recreated.

## es

- **Las excavadoras de la demo Site Pulse tienen su propio perfil de dispositivo.** Una excavadora no transporta carga ni tiene neumáticos, pero compartía el perfil de equipo con las cargadoras y los camiones, por lo que la tabla de la flota declaraba para ella carga útil y presión de neumáticos y mostraba "sin datos en el rango". El tipo excavadora usa ahora un perfil propio que declara solo combustible, temperatura del motor y horas de motor, con los mismos comandos y las reglas de bajo combustible y sobrecalentamiento, pero sin regla de neumáticos, de modo que esas celdas indican "no informa de esto". Una instancia de demo creada por una versión anterior conserva el perfil compartido hasta que se vuelva a crear.

## zh-CN

- **Site Pulse 演示中的推土机现在有自己的设备配置文件。** 推土机不载货也没有轮胎，却与装载机和运输卡车共用同一个设备配置文件，因此车队表为它声明了载重和胎压，并显示“范围内无数据”。推土机类型现在使用独立的配置文件，仅声明燃油、发动机温度和发动机小时数，命令以及低油量和过热规则保持不变，但没有轮胎规则，因此这些单元格显示“不上报此项”。由早期版本创建的演示实例在重新创建之前仍使用共用的配置文件。
