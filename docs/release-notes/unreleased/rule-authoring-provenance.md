## en

- **Rule authoring provenance.** Published device profile versions now record the publisher's stable principal ID and the set of doors their draft rules were saved through: Form, Canvas, Describe, product as code, or API. A later form edit preserves Describe's AI-assisted origin. Existing records read UNKNOWN; the existing publisher name and canvas graph are unchanged. Clients can optionally identify the save door; saves that omit it record API.

## es

- **Procedencia de la autoría de reglas.** Las versiones publicadas de los perfiles de dispositivo ahora registran el identificador estable de quien publica y el conjunto de vías usadas para guardar sus reglas en borrador: Formulario, Lienzo, Describir, producto como código o API. Una edición posterior en el formulario conserva el origen asistido por IA de Describir. Los registros existentes se leen como UNKNOWN; el nombre de quien publica y el grafo del lienzo se mantienen. Los clientes pueden indicar opcionalmente la vía de guardado; si la omiten, se registra API.

## zh-CN

- **规则编写来源。** 已发布的设备配置版本现在会记录发布者的稳定主体 ID，以及保存草稿规则时使用的入口集合：表单、画布、描述、产品即代码或 API。随后通过表单编辑不会抹去“描述”的 AI 辅助来源。现有记录显示为 UNKNOWN；原有发布者名称和画布图保持不变。客户端可选择指定保存入口；省略时记录为 API。
