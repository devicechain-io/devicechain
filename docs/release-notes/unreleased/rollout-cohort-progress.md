## en

- **Rollout progress by cohort.** The update-management GraphQL API now reports outcome counts for each rollout cohort and supports filtering targets by cohort. Counts use the same outcome rules as overall rollout progress.

## es

- **Progreso del despliegue por cohorte.** La API GraphQL de gestión de actualizaciones ahora muestra los recuentos de resultados de cada cohorte y permite filtrar los dispositivos de destino por cohorte. Los recuentos siguen las mismas reglas que el progreso global del despliegue.

## zh-CN

- **按批次查看更新进度。** 更新管理 GraphQL API 现在提供每个更新批次的结果计数，并支持按批次筛选目标设备。批次计数与整体更新进度采用相同的结果统计规则。
