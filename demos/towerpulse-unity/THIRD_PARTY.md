# Third-party content in Towerpulse

Every asset in this project that was not made for it is listed here, with where it came from
and the license it was used under. Only assets whose license allows redistribution in this
repository are accepted: CC0 / public domain by preference, or an equally permissive license.
Purchase rights alone (for example an asset store license) are not enough.

## Assets

There are none at present. Every model is made in-house by code (see below), and no texture,
font, sound or mesh from another source is in the project.

When an asset is added, record it here in a table with its name, the files it became, its source
URL, the version or date it was retrieved, and its license. If a model ever has to be replaced by
someone else's work, CC0 only (Kenney, Quaternius) and the license goes in the table.

## Original work

| Content | Files | Made with |
|---|---|---|
| Tower and annex buildings: curtain wall, floor slabs, zone volumes, core with lifts and stairs, roofs, entrances | `Assets/Towerpulse/Art/Models/tower*.glb`, `annex*.glb` | Generated by the Blender Python code in `ArtSource/` (Apache-2.0) |
| Rooftop air-handling unit and air-cooled chiller, with their fans | `Assets/Towerpulse/Art/Models/ahu*.glb`, `chiller*.glb` | Generated by `ArtSource/models/equipment.py` (Apache-2.0) |
| Desk, meeting table and chair | `Assets/Towerpulse/Art/Models/desk*.glb`, `meeting_table*.glb`, `chair*.glb` | Generated by `ArtSource/models/furniture.py` (Apache-2.0) |
| Office workers, standing and seated, in two variants | `Assets/Towerpulse/Art/Models/person_*.glb` | An original stylised figure generated by `ArtSource/models/people.py` (Apache-2.0); not derived from any character, scan or asset pack |
| Campus ground: lawn, plaza, paths, planters, trees, bollard lamps | `Assets/Towerpulse/Art/Models/campus_ground*.glb` | Generated by `ArtSource/models/ground.py` (Apache-2.0) |
| Campus layout: zones, furniture and seat placements, rooftop units, chillers | `Assets/Towerpulse/Data/campus_layout.json` | Generated by `ArtSource/layout.py` (Apache-2.0) |

None of the models is textured: colour comes from the flat materials of `ArtSource/towerpulse_kit.py`.
The buildings, equipment and furniture are generic and unbranded, and no real building, product or
logo was used as a reference that is part of this repository.

## Tools

Blender (GPL) is used to run the generator and is not distributed here: the `.glb` files it
writes are the generator's output, not Blender code. The scripts import its Python API only.

## Packages

Unity packages, once the project declares them in `Packages/manifest.json`, are fetched from the Unity registry under
their own licenses; none are vendored into this repository.
