## en

- **dcctl negotiates API capabilities.** Tenant and admin commands check the target schema before sending operations or input fields. Unsupported features report an upgrade remedy. With v1.7 and v1.8 instances, dcctl uses the conservative v1.7 API contract; preview features and features outside that contract require upgrading the instance to v1.9 for discovery. Newer instances advertise their actual schema to authenticated callers without enabling anonymous introspection. Commands and flags remain available.

## es

- **dcctl negocia las capacidades de la API.** Los comandos de tenant y administración comprueban el esquema de destino antes de enviar operaciones o campos de entrada. Las funciones no compatibles indican cómo actualizar. Con instancias v1.7 y v1.8, dcctl usa el contrato conservador de la API v1.7; las funciones en vista previa y las que están fuera de ese contrato requieren actualizar la instancia a v1.9 para su detección. Las instancias más recientes publican su esquema real a clientes autenticados sin habilitar la introspección anónima. Los comandos y las opciones siguen disponibles.

## zh-CN

- **dcctl 协商 API 能力。** 租户和管理命令在发送操作或输入字段之前检查目标实例的架构。不支持的功能会给出升级建议。对于 v1.7 和 v1.8 实例，dcctl 使用保守的 v1.7 API 契约；预览功能和超出该契约的功能需要将实例升级到 v1.9 才能发现。较新的实例向已认证的客户端提供实际架构，无需启用匿名自省。现有命令和参数仍然可用。
