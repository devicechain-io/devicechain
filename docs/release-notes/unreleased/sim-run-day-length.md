## en

- **Set harborpulse's day length from dcctl.** Run `dcctl sim run <name> --day-length 48m` to stretch one compressed sim day to 48 minutes. The default `0` keeps the scenario's own 24-minute day; negative values are refused, and the simulator validates its minimum day length.

## es

- **Configura la duración del día de harborpulse desde dcctl.** Ejecuta `dcctl sim run <name> --day-length 48m` para ampliar un día comprimido de simulación a 48 minutos. El valor predeterminado `0` conserva el día de 24 minutos del escenario; se rechazan los valores negativos y el simulador valida la duración mínima del día.

## zh-CN

- **通过 dcctl 设置 harborpulse 的一天时长。** 运行 `dcctl sim run <name> --day-length 48m`，将一个压缩模拟日延长至 48 分钟。默认值 `0` 保留场景自身的 24 分钟一天；负值会被拒绝，最短一天时长由模拟器校验。
