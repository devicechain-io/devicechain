# Third-party content in Sitepulse

Every asset in this project that was not made for it is listed here, with where it came from
and the license it was used under. Only assets whose license allows redistribution in this
repository are accepted: CC0 / public domain by preference, or an equally permissive license.
Purchase rights alone (for example an asset store license) are not enough.

Reference material used while modelling (photos, drawings, specification sheets) is never
committed, and is not listed here.

## Assets

There are none at present. The scene's look is made in-house: the models, props and vegetation
are built by code in `ArtSource/`, the terrain is painted from a generated colour map by a shader
in this project, and the effects' textures are drawn by the scene builder. (Earlier versions used
four CC0 terrain materials from ambientCG; they were removed when the terrain moved to the
stylized look.)

When an asset is added, record it here in a table with its name, the files it became, its source
URL, the version or date it was retrieved, and its license.

## Packages
