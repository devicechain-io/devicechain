## en

- **Dashboard viewport previews.** Preview layouts at 390, 768, 960, 1366, 1920 or 3840 pixels and review layout findings for that width. Return to Container to resume editing; preview choices never change the saved dashboard or live device bindings.

## es

- **Vistas previas de ancho del panel.** Previsualice los diseños a 390, 768, 960, 1366, 1920 o 3840 píxeles y consulte los problemas de diseño para ese ancho. Vuelva a Contenedor para seguir editando; las opciones de vista previa nunca cambian el panel guardado ni los enlaces de dispositivos en vivo.
