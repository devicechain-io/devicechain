## en

- **Console detail pages open tokens that contain `%`.** The device, tenant, tier, role, AI provider, identity provider, integration, provisioning profile, trust anchor and registry detail pages decoded the token in their address a second time. A token holding a `%` opened a different token, or the page failed to load. Each page now reads the token once.

## es

- **Las páginas de detalle de la consola abren tokens que contienen `%`.** Las páginas de detalle de dispositivos, tenants, niveles, roles, proveedores de IA, proveedores de identidad, integraciones, perfiles de aprovisionamiento, anclas de confianza y del registro decodificaban por segunda vez el token de su dirección. Un token con un `%` abría otro token, o la página no llegaba a cargarse. Ahora cada página lee el token una sola vez.

## zh-CN

- **控制台详情页可以打开包含 `%` 的令牌。** 设备、租户、等级、角色、AI 提供方、身份提供方、集成、预配配置文件、信任锚以及注册表的详情页会对地址中的令牌再解码一次。包含 `%` 的令牌会打开另一个令牌，或者页面无法加载。现在每个页面只读取一次令牌。
