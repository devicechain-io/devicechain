## en

- **Deleted entity events stay detached.** Events received before a customer, area, asset, group or device was deleted no longer reappear under a re-created entity with the same token when they are stored after the deletion was processed.

## es

- **Los eventos de entidades eliminadas permanecen desvinculados.** Los eventos recibidos antes de eliminar un cliente, área, activo, grupo o dispositivo ya no reaparecen bajo una entidad recreada con el mismo token cuando se almacenan después de procesar la eliminación.

## zh-CN

- **已删除实体的事件保持解除关联。** 在客户、区域、资产、组或设备删除前收到的事件，即使在删除处理完成后才存储，也不会再出现在使用相同令牌重新创建的实体下。
