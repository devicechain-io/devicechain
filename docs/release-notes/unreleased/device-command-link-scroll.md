## en

- **A link to a command opens on that command.** A device link of the form `/devices/<token>?tab=commands#command-<token>`, such as the one the approvals inbox builds, now scrolls to the command's row and highlights it briefly, on any page of the device's history. A command that is not on the loaded page is read by its token and pinned above the history without a Cancel button. A command that no longer exists, belongs to another device or cannot be read shows a note instead.

## es

- **Un enlace a un comando se abre en ese comando.** Un enlace de dispositivo con la forma `/devices/<token>?tab=commands#command-<token>`, como el que genera la bandeja de aprobaciones, ahora se desplaza a la fila del comando y la resalta brevemente, en cualquier página del historial del dispositivo. Un comando que no está en la página cargada se lee por su token y se fija sobre el historial, sin botón Cancel. Un comando que ya no existe, que pertenece a otro dispositivo o que no se puede leer muestra una nota.

## zh-CN

- **指向命令的链接会直接定位到该命令。** 形如 `/devices/<token>?tab=commands#command-<token>` 的设备链接（例如审批收件箱生成的链接）现在会滚动到该命令所在行并短暂高亮，无论它位于设备历史的哪一页。不在已加载页面中的命令会按令牌单独读取，并固定显示在历史上方，且不提供 Cancel 按钮。已不存在、属于其他设备或无法读取的命令会显示一条提示。
