## en

- **dcctl output.** JSON output and the terminal UI preserve ordinary kubeconfig plugin settings such as `AWS_PROFILE=default` and `AWS_REGION=us-east-1`. Values identified as secrets by their names or credential-like contents remain redacted.

## es

- **Salida de dcctl.** La salida JSON y la interfaz de terminal conservan los ajustes habituales de los complementos de kubeconfig, como `AWS_PROFILE=default` y `AWS_REGION=us-east-1`. Los valores identificados como secretos por sus nombres o por su contenido similar a credenciales siguen ocultándose.

## zh-CN

- **dcctl 输出。** JSON 输出和终端界面会保留 kubeconfig 插件的普通设置，例如 `AWS_PROFILE=default` 和 `AWS_REGION=us-east-1`。根据名称或凭据特征识别出的敏感值仍会被遮蔽。
